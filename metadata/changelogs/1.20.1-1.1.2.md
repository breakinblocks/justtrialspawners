# Just Trial Spawners 1.20.1-1.1.2

## Balance Changes

- Increased default trial spawner mob counts to better match vanilla difficulty expectations
  - `totalMobs`: 6 → higher baseline so a spawner run takes meaningful effort
  - `simultaneousMobs`: 2 → higher cap so encounters feel like a fight, not a trickle
  - `totalMobsAddedPerPlayer`: 2 → scales group difficulty more aggressively
- Ominous trial spawners now explicitly set their own elevated `totalMobs` and `simultaneousMobs` rather than inheriting the (previously very low) normal values

## Notes

- Previous defaults were low enough to make trial spawners trivial; this brings them closer to vanilla 1.21 feel
- Existing spawners in already-loaded worlds keep whatever values they were saved with — new spawners placed after updating will use the new defaults

## Included from 1.1.1

- Hardcoded the CurseForge project ID in `build.gradle` to fix automated publishing
