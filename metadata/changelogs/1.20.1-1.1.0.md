# Just Trial Spawners 1.20.1-1.1.0

## Migration System Improvements

- Added a chunk serializer mixin to rewrite chunk NBT before deserialization to fix block palette resolution
- Block palette properties from the old Trials mod are now correctly stripped, with the ominous vault state preserved via blockstate property
- Spawn egg entity extraction now handles maps correctly via item ID remapping
- Migrated trial spawners now use Just Trial Spawners default config values instead of reading the Trials mod's transient `Enemies`/`Killed` fields
- Migrated spawners and vaults now properly use `setChanged()` to persist converted data to disk
- The `enable_trials_migration` config now defaults to **false** — enable explicitly when transitioning a world from the Trials mod

## Bug Fixes

- Fixed `JTSEventHandler` event bus split — `LivingDeathEvent` and `LivingHurtEvent` now correctly fire on the Forge bus while `EntityAttributeCreationEvent` remains on the mod bus
- Fixed shearing loot table for Bogged: removed unreachable `minecraft:alternatives` entries in favor of proper weighted item entries

## Loot Table Corrections

- Trial spawners now eject from `spawners/trial_chamber/consumables` + `spawners/trial_chamber/key` (matching 1.21 vanilla) instead of vault-level rewards
- Ominous spawners eject from `spawners/ominous/trial_chamber/consumables` + `spawners/ominous/trial_chamber/key`
