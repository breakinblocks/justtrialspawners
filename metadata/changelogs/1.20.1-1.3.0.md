# Just Trial Spawners 1.20.1-1.3.0

## Added

- Added custom models and textures for individual trial spawners and vaults through `/trialspawner appearance` ([#3](https://github.com/breakinblocks/justtrialspawners/issues/3)).

## Fixed

- Fixed configured ominous spawners using normal rewards.
- Fixed ominous trials failing to start during spawner cooldown.
- Fixed spawn egg changes reverting after the next mob spawn.
- Fixed cleared mob and reward lists returning after reload.
- Fixed per-spawner spawn range settings being ignored.
- Fixed Breeze long jumps falling short of their targets.
- Fixed migrated vaults rejecting trial keys or requiring the wrong key type.
- Fixed Trials chunk migration running when disabled.
