# Just Trial Spawners 1.20.1-1.0.0

Initial release — a Forge 1.20.1 backport of Minecraft 1.21's Trial Chamber features.

## Features

### Trial Spawner
- Full state machine: inactive, waiting_for_players, active, waiting_for_reward_ejection, ejecting_reward, cooldown
- Player detection with configurable range
- Wave-based mob spawning with per-player scaling
- Reward ejection from configurable loot tables
- Ominous mode transformation when a player with Bad Omen approaches
- Ominous item spawner: periodically drops items above players/mobs during active ominous state
- Right-click with a spawn egg to set the next spawn mob type
- Custom block item renderer shows a spinning mob preview when configured
- Tooltip displays the currently configured mob
- Default spawner is pre-configured with zombie spawn data

### Vault
- Trial Key / Ominous Trial Key activation
- Per-player reward tracking (each player gets one reward per vault)
- Ominous vault variant with upgraded loot
- Cutout rendering for transparent textures

### Entities
- **Breeze** — Full AI (long jump, slide, shoot wind charges, stuck detection)
- **Bogged** — Skeleton variant with poison arrows, shearable for mushrooms via loot table
- **Wind Charge** — Authentic 1.21 knockback physics with eye-height direction vectors
- **Breeze Wind Charge** — Larger explosion radius, triggers redstone components (buttons, levers, trapdoors, doors, fence gates)

### Items
- **Trial Key** / **Ominous Trial Key**
- **Breeze Rod** — Crafts into wind charges
- **Wind Charge** — Throwable projectile
- **Ominous Bottle** — With amplifier system (0-4), scales Bad Omen duration
- **Breeze / Bogged Spawn Eggs**

### Mob Effects
- **Trial Omen** — Converted from Bad Omen at trial spawners
- **Wind Charged** — Wind burst on death
- **Weaving** — Cobwebs on death
- **Oozing** — Slimes on death
- **Infested** — Chance to spawn silverfish when hit

### Enchantments
- **Density** (I-V) — Weapon damage bonus, incompatible with Sharpness/Smite/Bane
- **Breach** (I-IV) — Armor bypass via damage multiplier
- **Wind Burst** (I-III) — Wind burst on attack, treasure-only

### Commands
- `/trialspawner edit [pos]` — Opens FTB Library NBT editor for held item or placed block
- `/trialspawner give <entity> [totalMobs] [simultaneousMobs] [ticksBetweenSpawn]`
- `/trialspawner addmob <pos> <entity> [weight]`
- `/trialspawner setconfig <pos> <key> <value>`
- `/trialspawner info <pos>`
- `/trialspawner clearmobs <pos>`

### Creative Tab
- All blocks, items, and entities
- Pre-configured trial spawners for 36 vanilla + mod hostile mobs
- Ominous Bottle variants for all 5 amplifier levels

### Migration from the Trials Mod
- Automatic registry remapping for blocks, items, block entities, entity types, mob effects, and enchantments
- Lazy NBT conversion on chunk load for trial spawners and vaults
- Ominous vault state fixup on first server tick
- Entity type remapping preserves alive breeze/bogged/wind_charge entities
- Configurable via `enable_trials_migration` server config

## Dependencies
- Forge 1.20.1 (47.3+)
- FTB Library 2001.2.12+
- Architectury API 9.2.14+

## Known Issues
- Trials mod decorative blocks (tuff/copper variants) are not replaced and will be lost
- Vault blocks lose facing direction during migration (Trials vault had no facing property)
- Held trial spawner items retain old NBT until placed and re-picked-up after migration
- Trials mod potions, banner patterns, paintings, sherds, and music discs are not remapped
